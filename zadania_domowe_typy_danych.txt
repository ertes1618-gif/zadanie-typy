Cwiczenie 1.3

"5" * 2 -> "55"
"10" - 5 -> błąd

JavaScript:
"5" + 3 -> "53"
"5" * 2 -> 10
"10" - 5 -> 5
True + 1 -> 1

Lekcja 3
Cwiczenie 3.1
Współrzędne GPS: double, bo potrzeba dużej precyzji
Kolor piksela: float, bo wystarczy mniejsza dokładność
Obliczenia naukowe: double, wysoka precyzja
Saldo konta: double (lub Decimal), unikamy błędów zaokrągleń

Cwiczenie 3.2
Dokładne: 0,5; 0,25; 0,75; 0,125; 1,5
Reguła: Liczbę da się zapisać dokładnie, gdy mianownik ułamka jest potęgą dwójki.

Cwiczenie 3.3
Wyniki pokazują błędy precyzji zmiennoprzecinkowej. Zaskakuje wynik 0.1 + 0.2 == 0.3 dający False.

Cwiczenie 3.4
Przyczyna: Porównywanie floatów bezpośrednio bywa błędne przez zaokrąglenia.
Poprawa:
def czy_zaplacono(kwota_wplacona, kwota_do_zaplaty):
    return abs(kwota_wplacona - kwota_do_zaplaty) < 1e-9
